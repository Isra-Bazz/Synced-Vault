## **Week 1: JavaScript and Framework Fundamentals**

### **Day 1: Core JavaScript Refresher**
- **Topics**:
  - ES6+ Features: `let`, `const`, arrow functions, template literals, destructuring, modules.
  - Basic DOM manipulation and event handling.
  - Fetch API for basic HTTP requests.
- **Activities**:
  - Create a simple webpage that dynamically updates content using JavaScript.
  - Add interactivity through event listeners (e.g., button clicks).
- **Resources**:
  - [JavaScript.info](https://javascript.info/)
  - Practice challenges: [Exercism JavaScript](https://exercism.io/tracks/javascript)

---
### **Day 2: Modern JavaScript Concepts**
- **Topics**:
  - Promises and `async/await`.
  - Closures and higher-order functions.
- **Activities**:
  - Build a script that fetches data from an API (e.g., [JSONPlaceholder](https://jsonplaceholder.typicode.com/)) and renders it on the page.
  - Display the data dynamically with DOM manipulation.
- **Resources**:
  - *You Don’t Know JS* (Kyle Simpson)
  - API Practice: [JSONPlaceholder](https://jsonplaceholder.typicode.com/)

---
### **Day 3: Introduction to React**
- **Topics**:
  - React basics: Components, JSX, props.
  - Setting up a React project with `create-react-app`.
- **Activities**:
  - Build a simple React app that displays a list of items passed as props.
- **Resources**:
  - Official React Docs: [reactjs.org](https://reactjs.org/)

---
### **Day 4: React State and Events**
- **Topics**:
  - State management with `useState`.
  - Handling events in React.
- **Activities**:
  - Extend your React app to allow users to add or remove items from the list.
- **Resources**:
  - Tutorials: [Scrimba React Course](https://scrimba.com/learn/learnreact)

---
### **Day 5: React Routing**
- **Topics**:
  - React Router: Setting up routes, `Link`, and `useParams`.
- **Activities**:
  - Add navigation to your React app (e.g., home page and details page).
- **Resources**:
  - React Router Docs: [reactrouter.com](https://reactrouter.com/)

---
### **Day 6: API Integration in React**
- **Topics**:
  - Fetching data from APIs within React components.
  - Using `useEffect` for side effects.
- **Activities**:
  - Fetch and display data from a public API (e.g., [OpenWeatherMap](https://openweathermap.org/)).
- **Resources**:
  - Blog: [Using Fetch with React](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch)

---
### **Day 7: React Project**
- **Project**: Build a basic weather app.
  - Input: Search for a city.
  - Output: Display weather data from the OpenWeatherMap API.
- **Deliverables**:
  - Clean and responsive UI.
  - Functional search and error handling.
- **Resources**:
  - Deployment: Use [Vercel](https://vercel.com/) to host your app.
